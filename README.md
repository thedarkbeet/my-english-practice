# English — учебная тетрадь

Учебный сайт на существующем Next.js 16 / React 19 / shadcn (Base UI) проекте. Русский интерфейс, адаптивная навигация, теория, ответы и домашние работы 1–31.

## Запуск

```sh
pnpm install
pnpm dev
```

Откройте http://localhost:3000. Для production: `pnpm build`, затем `pnpm start`.

## Материалы

Исходник — `HomeWork_spreadsheet.xlsx`, он не изменяется. Повторяемый импорт выполняется стандартной библиотекой Python 3, дополнительные пакеты не нужны:

```sh
pnpm import:course
```

`data/course.json` содержит 1403 упражнения, правила, справочник предлогов и пояснения. `data/import-archive.json` сохраняет старые заполненные ответы и заглушки для аудита, в приложение не импортируется. Идентификатор упражнения зависит от работы, ячейки и текста вопроса: изменение вопроса не должно присвоить ему чужой старый ответ.

Работа 16 пуста; 23–31 заполнены заглушками, поэтому видны как недоступный материал и не входят в прогресс. Два эталона отсутствуют (Ответы!C72, X85). Заголовки и учебные пояснения не превращаются в поля ввода. Языковые формулировки преподавателя сохранены; полная лингвистическая редактура не выполнена. Темы на карточках — краткие редакционные названия для навигации.

## Прогресс

Ответы и самостоятельные отметки сохраняются в localStorage браузера; доступны экспорт и импорт JSON на главной странице. Регистрации, базы данных и межустройственной синхронизации нет. Импорт заменяет текущее состояние после подтверждения; неизвестные ID и повреждённые данные отклоняются. Не очищайте данные браузера без резервной копии.

Сравнение нормализует регистр, пробелы и апострофы. Несовпадение с образцом не означает неверный перевод. Завершение и повторение отмечает сам ученик; показ ответа не увеличивает прогресс автоматически.

## Проверки

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Для тестов нужен Node.js с поддержкой встроенного запуска TypeScript (например, Node 24+). Тесты проверяют полноту импорта, исключение заглушек, сохранность пояснений, сравнение и валидацию резервных копий. ESLint закреплён на совместимой с React-плагином ветке 9.

## Структура

- `scripts/import_course.py` — воспроизводимый импорт XLSX без исполнения формул.
- `lib/course.ts`, `lib/progress.ts` — материалы и правила работы с прогрессом.
- `components/course/` — оболочка, список работ, упражнения, теория и ответы.
- `app/` — маршруты главной, правил, теории, ответов и работ.
- `IMPLEMENTATION_PLAN.md` — исходный анализ и план.
